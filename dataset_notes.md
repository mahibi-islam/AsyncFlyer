The paper links the public Kaggle dataset: https://www.kaggle.com/datasets/sanchitagholap/crop-and-fertilizer-dataset-for-westernmaharashtra. The page describes a Western Maharashtra district-wise crop and fertilizer recommendation dataset with fields including District Name, Soil color, Nitrogen, Potassium, Phosphorus, pH, Rainfall, Temperature, Crop, Fertilizer, and Link. It is labeled as a classification/recommender dataset and is marked CC0 Public Domain. The code uses the crop column as the target and numeric soil/environment fields as features; humidity and moisture are optional because they are not listed on the linked page.
